# 작업이야기 (TaskIyagi)

**모든 리눅스 데스크톱에 작업표시줄 하나 — GNOME·KDE Plasma·XFCE·Cinnamon·MATE·LXQt·sway·Hyprland. 시작 메뉴·트레이·달력·포스트잇을 한 패널에.**

[English](README.md) · [한국어](README_ko.md)

## 왜 작업이야기인가

- **어떤 데스크톱이든 같은 패널.** GNOME 에서 KDE 로 옮기거나 Hyprland 를 써 봐도 작업표시줄·고정 앱·메모가 그대로입니다. 작업이야기가 데스크톱을 알아보고 맞춰 동작하므로 설정할 것이 없습니다.
- **익숙한 시작 메뉴와 작업표시줄.** 분류별 앱과 실시간 검색, 열린 창이 모두 막대에, 클릭 한 번으로 최소화·앞으로.
- **시계 안에 하루 일정.** 메모와 알림이 달린 달력, 포스트잇, 이달 할일, 잠깐 할일.
- **빠른 설정이 안에.** 음량·Wi-Fi·블루투스·배터리·야간 조명·CPU·메모리를 설정 창 없이.
- **다중 모니터를 제대로.** 패널을 둘 모니터를 고르고, 모니터를 꽂고 빼고 배치·배율을 바꿔도 따라갑니다.
- **내 취향대로.** 스킨·색·아이콘 크기·위/아래 위치·자동 숨김.

## 기능

### 시작 메뉴·작업표시줄
- 분류별 앱, 즐겨찾기, 실시간 검색, 프로그램 직접 추가
- 열린 창과 활성 창 표시, 창 묶기, 앱 고정, 강제 종료

### 시스템 트레이
- StatusNotifierItem·XEMBED 둘 다 — 요즘 앱도 옛 앱도 다 뜹니다

### 시계·달력·메모
- 달력, 메모, 포스트잇, 알림, 이달 할일, 잠깐 할일

### 빠른 설정
- 음량 · Wi-Fi · 블루투스 · 배터리 · 야간 조명
- CPU·메모리 사용량, 시스템 모니터, 네트워크 감시

### 그 밖에
- 계산기(패널 팝업 또는 별도 창)
- 한/영 입력 표시, 전원 메뉴, 설정 바로 가기
- 전역 단축키(`Shift+Esc` 시스템 모니터, `Shift+F1`~`F5` 지정한 프로그램)

## 지원 데스크톱

| 데스크톱 | 창 목록 | 트레이 | 준비 |
|---|---|---|---|
| GNOME (우분투·페도라 기본) | ✅ | ✅ | 한 번 다시 로그인 |
| KDE Plasma | ✅ | ✅ | 없음 |
| labwc · Wayfire · niri · Hyprland | ✅ | ✅ | 없음 |
| sway | ✅ | ✅ | 없음 |
| XFCE · MATE · Cinnamon · LXQt | ✅ | ✅ | 없음 |

GNOME Wayland 에서는 창 목록을 보려고 처음 실행할 때 작은 도우미 확장을 설치합니다. 그래서 한 번 다시 로그인해야 합니다.

## 다운로드

우분투(deb)·페도라(rpm)·아치(pkg.tar.zst)·그 밖의 배포판(AppImage·zip)용 패키지가 **[Releases](https://github.com/iyagicom/TaskIyagi/releases)** 에 올라올 예정입니다.

GNOME 만 쓴다면 **[패널이야기(PanelIyagi)](https://github.com/iyagicom/PanelIyagi)** 를 지금 받을 수 있습니다.
